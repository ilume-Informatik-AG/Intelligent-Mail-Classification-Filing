# AI Mail Classification & Filing Engine

**Intelligent email sorting based on Camunda 8** — by ilume Informatik AG

> **Listing only.** This repository contains the media assets for the Camunda Marketplace listing. It does not contain source code, process models or deployable artifacts, and the solution is not offered as open source.

## About the solution

The AI Mail Classification & Filing Engine automatically classifies incoming emails by topic and files them into the matching Microsoft Outlook folder. Personal data is masked before any AI processing (privacy by design), the classification runs on Claude via AWS Bedrock in an EU region, and unclear emails are placed in a review folder for a human decision. Camunda 8 orchestrates the entire end-to-end process.
